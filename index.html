GitHub Read/Write Test

A small test application for reading and writing JSON data in a GitHub repository.

Repository

Authentication

For this initial test only: enter a GitHub fine-grained Personal Access Token with repository Contents read/write permission. The token is used only in memory by this page and is never saved to the repository.

Data

Ready.

How this test works

  1. Read the JSON file from the public GitHub repository.
  2. Edit the JSON in the browser.
  3. Write the updated file back through the GitHub Contents API.
  4. GitHub creates a commit containing the change.
