Test Procedure

  1. The application automatically reads the JSON data when the page loads.
  2. Click Increment Counter.
  3. Click Write to GitHub.
  4. Verify that GitHub reports a successful commit.
  5. Reload this page.
  6. Verify that the updated counter is read back from GitHub.

Test 2 Architecture

Unlike Test 1, this application does not contain a GitHub Personal Access Token.

The browser communicates with the Cloudflare Worker, and the Worker communicates with GitHub using the encrypted GITHUB_TOKEN secret.

This provides the basic architecture we can use for future HTML/JavaScript applications that need controlled read/write access to GitHub data.
